# Java Projects

Repositório com projetos práticos em Java focados em Programação Orientada a Objetos (POO), boas práticas e desenvolvimento backend.

## Projetos

| Projeto | Descrição | Conceitos aplicados |
| :--- | :--- | :--- |
| [car-registry-cli](./car-registry-cli) | Sistema de cadastro e consulta de carros via terminal. | Encapsulamento, herança (`Car` / `Toyota`), validações, listas (`ArrayList`) e tratamento de exceções. |
| [car-registry-web](./car-registry-web) | Evolução do sistema para a web com backend em Java puro (`HttpServer`) e frontend em HTML, CSS e JavaScript. | API REST (`GET` / `POST`), JSON, servidor HTTP nativo do Java e integração frontend-backend. |

## Requisitos

- Java JDK 17 ou superior
